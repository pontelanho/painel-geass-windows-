# GEASS - The Power of the King

Um painel de puxar dados :)

## Como instalar

O processo foi automatizado para funcionar direto no Windows. Siga apenas estes passos:

1. **Baixe e extraia:** Faça o download deste repositório (ZIP) e extraia a pasta no local onde você quer que o programa fique guardado no seu PC (por exemplo, na pasta Documentos). *Atenção: Não apague ou mova essa pasta depois de instalar.*
2. **Ícone:** Certifique-se de que a imagem `geass.ico` está dentro da pasta que você acabou de extrair.
3. **Execute o instalador:** Dê dois cliques no arquivo `instalador.bat`. 

O instalador vai pedir permissão de administrador. Ele precisa disso para verificar seu PC e baixar silenciosamente o **Python** e o **Git Bash** (caso você ainda não tenha), além de instalar os módulos necessários. É só esperar a tela preta terminar o processo.

## Como usar

Assim que o instalador avisar que terminou, o sistema em si está pronto. 

Você só vai precisar se dirigir ao xbuscas.net, criar uma conta, abrir seu perfil, abastecer sua conta via algum método de pagamento, pegar seu token pessoal, e substituir em cada um dos arquivos .py "INSIRA SEU TOKEN PESSOAL AQUI" pelo token pessoal da sua conta (mantendo as aspas).

Para usar o painel, basta ir na sua **Área de Trabalho** (ou no Menu Iniciar do Windows) e abrir o atalho **Geass Terminal**. O painel já vai abrir configurado e pronto para receber os comandos.
